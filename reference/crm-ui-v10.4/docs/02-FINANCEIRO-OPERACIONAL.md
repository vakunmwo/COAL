# Financeiro Operacional

O módulo organiza uma pequena empresa, mas não substitui contabilidade.

## Indicadores

- recebido;
- a receber;
- atrasado;
- despesas pagas;
- despesas a pagar;
- recorrência.

## Conta usada

```text
pagamentos recebidos registrados
- estornos registrados
- despesas pagas registradas
= resultado operacional registrado
```

Não chamar de lucro contábil.

## Orçamento

```text
diferença = realizado pago - planejado
```

## Fluxo projetado

Só existe com saldo inicial registrado:

```text
saldo inicial
+ entradas previstas
- saídas previstas
= saldo projetado
```

Sem saldo inicial, o CRM mostra dados insuficientes.

## Recorrência

Infraestrutura e serviço ficam separados.
