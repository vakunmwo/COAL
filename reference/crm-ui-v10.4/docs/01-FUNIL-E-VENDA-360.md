# Funil e Venda 360

## Etapas

Pesquisa → Evidência → Abordagem → Diagnóstico → Oferta → Proposta → Decisão.

## Venda 360

Blocos verticais:
- situação;
- ações principais;
- Para avançar;
- histórico;
- proposta;
- decisão comercial.

### Ganhou
Cria/ativa cliente, projeto e recebíveis.

**Não registra pagamento automaticamente.**

### Perdeu
Motivo obrigatório.

### Não agora
Data e condição de retorno obrigatórias.

## Gate

`Para avançar` é suave por padrão.

Pendência permite override com motivo registrado.
