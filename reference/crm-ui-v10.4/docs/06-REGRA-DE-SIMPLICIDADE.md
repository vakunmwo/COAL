# Regra de simplicidade V10.3

1. Uma cena principal por vez.
2. Subvisões trocam o bloco central; não abrem novas abas.
3. Botão visível precisa funcionar, explicar bloqueio ou sair da UI.
4. Termos técnicos ficam fora do fluxo comum.
5. Funil, cliente, trabalho e financeiro continuam ligados pela mesma entidade.
6. Nenhum indicador financeiro usa valor de venda como dinheiro recebido.
