# Dados do laboratório

Todos os nomes, valores, contatos e estados desta V10.2 são **sintéticos**.

Eles não representam:
- clientes reais;
- faturamento real;
- despesas reais;
- saldo bancário real;
- obrigações reais da COAL UP.

O objetivo é validar a experiência antes de conectar fontes reais.
