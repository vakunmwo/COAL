# V10.4 — Readability + Funnel UX Lab

**Frente:** COAL UP Marketing e Presença Digital — CRM interno.

## O que mudou

- tipografia operacional ampliada;
- sans-serif virou fonte principal de leitura;
- botões e inputs ampliados;
- Funil desktop com colunas de 300–320px;
- cabeçalho de etapa com potencial, média observada no laboratório e atenção;
- mobile deixou de comprimir Kanban;
- mobile usa uma etapa ativa por vez;
- Acompanhamentos dividido em Vencidos / Hoje / Próximos / Sem próximo passo;
- Propostas agrupadas por estado;
- Venda 360 aprofundada;
- `nextActionTaskId` adicionado como ponte conceitual para uma Action real.

## Importante

Este é um UX Lab.

Os dados continuam sintéticos.

A média por etapa exibida é da simulação atual, não SLA real.

O Funnel Engine de backend ainda não foi ligado.
