# Mobile Funnel V10.4

## Decisão

Não existe Kanban espremido no celular.

A experiência usa:
- strip horizontal de etapas;
- uma etapa ativa;
- cards verticais;
- botão Avançar etapa dentro da Venda 360.

## Venda 360

No mobile:
- ocupa `100dvh`;
- close fica no cabeçalho sticky;
- conteúdo rola internamente;
- safe-area preservada.

## QA necessário

- 320×568
- 360×800
- 390×844
- 430×932
- 844×390

Safari físico continua gate separado.
