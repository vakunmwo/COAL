# 2. Conflitos ainda abertos

## TV

### Margem real UniTV
Crédito conhecido: R$9,80.
Margem líquida atual: **não consolidada**.

Antes de projeção:
perguntar taxa real + receita + custos.

### Lead orgânico
Teste de 1h saiu.
Não está confirmado se orgânico recebe:
- 7 dias;
- ou nenhum teste.

### Indicador inativo
Arquivos antigos se contradizem:
- uma regra exige indicador ativo;
- uma matriz antiga autorizava inativo.

**Perguntar antes de operar.**

### Churn
Metas antigas não são medição observada.
Não projetar carteira como se meta fosse dado real.

### Clientes ativos
Números de agosto envelheceram.
Confirmar antes de projeção.

# 3. Operador / dinheiro

## Salário, função e horas
Fontes antigas podem estar desatualizadas.

Não usar:
- salário;
- cargo;
- receita/hora;
- horas por frente;

como atuais sem confirmação.

# 4. Marketing

## Receita total da frente
Nany é cliente pagante confirmada no legado.

Quero Pizza:
- Fase 1 concluída;
- valor informado: R$300;
- a base consolidada não marca explicitamente o estado financeiro do pagamento.

Não somar como receita recebida sem confirmação.

Closet Rosa:
- proposta/demo construída;
- valor de referência R$1.490;
- condição portfólio R$500;
- não está registrada aqui como contrato fechado.

## Manutenção
Regra antiga “sempre incluir manutenção” foi revogada como regra universal.

Agora:
- infraestrutura é uma coisa;
- manutenção é outra;
- cada contrato define.

# 5. Cliente real

Sempre perguntar quando falta:
- política;
- preço;
- ticket médio;
- estoque;
- história;
- título/cargo;
- prazo;
- autorização de portfólio;
- login/acesso.

Demo não transforma dado fictício em dado real.

# 7. Coisas corrigidas mais de uma vez

- teste de 1h não existe;
- entrega TV já foi automatizada;
- não voltar ao white-label por padrão;
- não sugerir contratação;
- não misturar laranja da TV com Marketing;
- prompt antes de gerar imagem da CoalUP Marketing;
- site de cliente é personalizado;
- hospedagem não é manutenção;
- pesquisa de busca não é faturamento perdido;
- mobile precisa ser testado de verdade.
