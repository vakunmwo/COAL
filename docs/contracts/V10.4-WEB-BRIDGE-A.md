# 4. Pipeline

```text
validate
→ normalize
→ anti-abuse
→ insert lead_capture
→ dedupe
→ create/link contact + organization
→ create/link lead
→ create commercial_case
→ attach published funnel version "Entrada pelo site"
→ create first task
→ domain event
→ audit/system log
```

# 5. Dedupe

Normalizar telefone.

Não auto-merge.

Estados:

```text
new
possible_duplicate
linked_existing
rejected
```

# 6. Resposta pública

Sucesso:

```json
{
  "ok": true,
  "message": "Recebemos sua solicitação."
}
```

Erro de validação:
mensagem útil sem expor estrutura interna.

# 7. Segurança

- não usar sessão administrativa;
- rate limit;
- honeypot;
- limite de tamanho;
- prepared statements;
- validação server-side;
- log de rejeições;
- sem IDs internos na resposta;
- nenhuma consulta pública ao Funil.
