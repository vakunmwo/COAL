# PHP

Recomendação:

- front controller simples;
- PDO com prepared statements;
- `PDO::ATTR_ERRMODE = PDO::ERRMODE_EXCEPTION`;
- `PDO::ATTR_EMULATE_PREPARES = false`;
- UTC na aplicação e conexão;
- respostas JSON padronizadas;
- transações explícitas em mutações de domínio.

# Organização de serviço

```text
Http Controller
    ↓ valida request básico
Application Service
    ↓ regra / transação
Repository
    ↓ SQL preparado
MySQL
```

Controller não deve implementar regra de Funil.

# TransitionCommercialCaseService

É o núcleo do diferencial.

Responsável por:
- lock pessimista;
- optimistic version check;
- requirement evaluation;
- override;
- criação Opportunity quando necessária;
- EXIT + ENTER;
- próximo passo explícito;
- domain events;
- audit;
- commit/rollback.

# Segurança da rota `/crm/`

`.htaccess`/servidor deve garantir:
- HTTPS;
- headers de segurança;
- sem listagem de diretório;
- `noindex`;
- `DirectoryIndex index.php`.

A proteção real é autenticação/autorização no PHP, não “URL escondida”.
